# 🌙 PraySync

**PraySync** is a lightweight, focused tool that instantly prints today's accurate Salah (prayer) times for any city in the world and displays a real-time countdown to the next prayer. 

## ✨ Core Features

* **Universal City Lookup:** Input any city name globally to instantly fetch today's prayer schedule.
* **Daily Timings:** Accurately prints the schedule for Fajr, Dhuhr, Asr, Maghrib, and Isha.
* **Smart Countdown:** Automatically compares the current time against the fetched schedule to display exactly how long remains until the next Salah.
* **Minimalist Output:** Designed to do exactly what is required—no bloat, just the times and the countdown.

## 💻 Example Output

```text
$ praysync --city "Karachi" --country "Pakistan"

🌙 PraySync - Today's Timings for Karachi, Pakistan

Fajr:    05:26 AM
Dhuhr:   12:16 PM
Asr:     04:11 PM
Maghrib: 05:47 PM
Isha:    07:05 PM

⏳ Next prayer is Isha in 1 hour and 18 minutes.
